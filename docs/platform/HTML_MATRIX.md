# Correspondencia con el HTML

Referencia original: `references/pipeline-city.html`, inspeccionada tras extraer localmente sus recursos sin ejecutar el bundle. El nuevo código no depende de su runtime, CDN ni nombres de cliente.

| Elemento | Resultado |
|---|---|
| Panel claro, Inter, radios, bordes y jerarquía discreta | Conservado con componentes React y fuentes locales |
| Sidebar y empresa activa | Navegación y selector con membresía real; cambio limpia estado/caché |
| Inicio, briefing y preguntas | Datos autorizados calculados, estados vacíos/error y modo demo explícito |
| Chat y fuentes | Conversaciones persistentes, worker, SSE/poll, bloques validados y evidencia consultable |
| Ciudad opcional | SVG determinista por módulos y permisos; selección, tabla y contexto del chat |
| Acciones | Separadas en propuesta, aprobación y ejecución local versionada |
| Tareas y rutinas | Persistentes; resultados internos y documentos, sin enviar mensajes externos |
| Conocimiento | Fuente declarada, tipo, vigencia, versiones y olvido; no modifica contabilidad |
| Informes | HTML, PDF real y CSV con metodología, cobertura y fuentes |
| Presentaciones | Diapositivas editables, HTML y PDF; Slides/PPTX pendientes |
| Studio | Gráficos SVG reales; trabajos de imagen/vídeo bloqueados sin integración |
| Conexiones | Catálogo honesto, importación y HubSpot de lectura con contratos; otros proveedores pendientes |
| Personas y roles | Acceso por organización/recurso/departamento; invitación privada de un uso |
| Modelos y presupuesto | Configuración revisada, reservas atómicas y proveedor opcional; no catálogo ficticio de modelos |
| Privacidad | Construcción positiva del envelope y bóveda local; sin promesas de anonimato absoluto |
| API externa | Consultas predefinidas e informes agregados; claves acotadas y revocables |
| Voz, MCP y webhooks | Apagados hasta implementar y verificar sus autorizaciones/salidas |
| “Nada se almacena” / precios/conexiones ficticias | Eliminados; retención y dependencias reales se explican |
| Ciudad cinematográfica anterior | Conservada en `/demo`, separada del núcleo transaccional de `/app` |

La demo no usa nombres, KPI ni respuestas del HTML como datos reales. Las dos organizaciones seed son ficticias. Las extensiones pendientes aparecen como tales, sin resultados inventados.
